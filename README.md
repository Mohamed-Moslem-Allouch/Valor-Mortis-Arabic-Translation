## 📖 About | نبذة عن التعريب

Full Arabic Localization Mod for **Valor Mortis (2026)** (PC Version).

After reverse-engineering and unpacking the original Unreal Engine 5 Zen/IoStore packages, I am pleased to present a complete, native, and high-fidelity Arabic localization. This mod translates all in-game text, menus, tutorials, dialogue, and lore while correcting right-to-left subtitle alignment and speaker name layout.

تعريب كامل وشامل للعبة الرعب التاريخية **Valor Mortis (2026)** على الكمبيوتر (PC).  
بعد الهندسة العكسية وفك حزم المحرك الأصلية (Unreal Engine 5 IoStore)، يسرني تقديم هذا التعريب المتكامل لكافة نصوص وقوائم وتلميحات وقصة اللعبة، مع إصلاح اتجاه ظهور شريط الحوارات وأسماء الشخصيات لتتناسب تماماً مع اتجاه القراءة العربي الصحيح.

---

## ✨ Features | مميزات التعريب

- 📜 **100% Comprehensive Translation:** All story dialogues, UI menus, tutorials, items, and settings are fully localized.
- 💬 **Fixed Dialogue Layout:** Speaker names and dialogue lines are properly aligned from right-to-left (`[الاسم]: الحوار`).
- 🔤 **Authentic Arabic Typography:** High-quality Arabic fonts (`Amiri` & `CrimsonText`) adapted to maintain the dark, medieval atmosphere of the game.
- 🌐 **Multilingual Safe:** Replaces only the French slot without breaking English or other original language fonts.
- ⚡ **Zero Hassle:** Available as a direct drag-and-drop package or a lightweight 5-second automatic patcher.

## 🛠️ Installation | طريقة التثبيت

### English

1. Download the latest release from the [Releases](../../releases) tab.
2. Copy the `ValorMortis` folder and paste it directly into your main **Valor Mortis** game root directory (where `ValorMortis.exe` is located).
3. Accept replacing existing files when prompted.
4. *(Optional / Lightweight Version)*: If using the batch patcher, simply run `Install_Arabic.bat` in your game root folder.
5. Launch the game, go to **Settings → Language**, and select **`Français`** (it has been completely replaced with Arabic).
6. Enjoy the game in pure native Arabic!

### العربية

1. قم بتحميل أحدث إصدار من قسم [Releases](../../releases).
2. انسخ مجلد `ValorMortis` والصقه مباشرةً داخل المجلد الرئيسي للعبة **Valor Mortis** (حيث يوجد ملف `ValorMortis.exe`).
3. وافق على استبدال الملفات عند ظهور رسالة التأكيد.
4. *(اختياري / في حال استخدام النسخة الخفيفة)*: شغّل ملف `Install_Arabic.bat` الموجود بجانب ملف تشغيل اللعبة وانتظر ثوانٍ معدودة.
5. شغّل اللعبة، ثم اذهب إلى **الإعدادات (Settings) → اللغة (Language)**، واختر **`Français`** (ستجد اللعبة تحولت بالكامل إلى العربية).
6. استمتع بتجربة اللعبة باللغة العربية الأصلية الخالصة!
